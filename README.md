 «Формула-1» (англ. Formula One, Formula 1, F1) — чемпионат мира по кольцевым автогонкам на спортивных машинах с открытыми колёсами (болидах). Проводится ежегодно и состоит из нескольких этапов — Гран-при. 
 
## Правила 🧠
1. Система начисления очков. Очки получают первые десять финишировавших пилотов, причём победитель зарабатывает 25 баллов, серебряный призёр — 18, а обладатель третьего места — 15. Далее баллы уменьшаются по схеме 12-10-8-6-4-2-1. Дополнительный балл может получить гонщик, показавший самый быстрый круг гонки, но только если он финишировал в первой десятке.
2. Регламент технических характеристик машин. Болиды разрабатываются по жёстким стандартам, установленным FIA.
3. Выбор шин. Каждая команда должна использовать минимум два состава шин за гонку.

### Команды 💪

В чемпионате мира по автогонкам в классе «Формула-1» участвуют как текущие, так и исторические команды. Чемпионат разыгрывается в серии гонок (Гран-при), проводимых по всему миру, и команды борются за титулы чемпиона мира среди гонщиков («личный зачёт») и чемпиона мира среди конструкторов («кубок конструкторов»).

Болид «Формулы-1» (болид «Ф-1») — гоночный автомобиль, созданный специально для соревнований в одноимённой автоспортивной дисциплине. Не предназначен для передвижения по дорогам общего пользования. Каждую такую машину разрабатывают индивидуально по заказу спортивной команды.
